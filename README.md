## 4).В цій частині реалізація окремої функції для пошуку добутку головної діагоналі
### Функція пробігає циклом по діагоналі матриці (де індекси рядка і стовпчика збігаються: i == j) і перемножує їх між собою, повертаючи загальний добуток
```c
long long calculateMainDiagonalProduct(int n, int a, int matrix[n][n]) {
    long long prod = 1;
    for (int i = 0; i < n; i++) {
        prod *= matrix[i][i];
    }
    return prod;
}
}
```
